# Results and B-roll

Upload everything straight into this folder: results, testimonials, DMs, screenshots, photos, B-roll, journey
pictures, notes. No need to sort or rename anything.

- The website takes up to 100 files per upload, so do big batches in rounds.
- Videos over 25 MB go in the [Results and B-roll release](https://github.com/eliascroesus/jeanfx-vsl/releases/new?tag=results-and-b-roll&title=Results%20and%20B-roll) instead (see the main README).
