# Thank-you raw footage

The raw, unedited recording of Jean's thank-you video (the one to edit 1:1 in the style of
[`thank-you-vsl-reference/`](../thank-you-vsl-reference/)).

- **The recording:** it'll almost always be over 25 MB, so upload it to the
  [Thank-you raw footage release](https://github.com/eliascroesus/jeanfx-vsl/releases/new?tag=thank-you-raw-footage&title=Thank-you%20raw%20footage).
  If GitHub asks about the tag, pick **Create new tag … on publish**, drag the file(s) into the box at the bottom
  ("Attach binaries"), wait until every file has finished uploading, then click **Publish release**.
- **Anything small** (screenshots, the page the video sits on, notes): upload it straight into this folder with
  **Add file → Upload files**.

If it was recorded in several takes or with separate audio, upload every file and note the order in a `notes.md` here.
