# Fonts

Static instances of two Google Fonts (SIL Open Font License 1.1, free for commercial use and redistribution):

- **Archivo** at width 125 (Expanded), weights 600/800/900: the wide all-caps display face for the thank-you
  video's graphics (closest free match to the Monument Extended / Druk Wide look in Iman Gadzhi's videos).
- **Caveat** Bold: the handwritten accent lines.

Captions stay in Inter Display (installed system-wide).
