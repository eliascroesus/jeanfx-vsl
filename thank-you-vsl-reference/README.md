# Thank-you VSL reference

The uploaded reference is AB Trades' thank-you video (`abnasdaq-thankyou.mp4`). Every element of it is broken down
in [BREAKDOWN.md](BREAKDOWN.md) (structure, captions, text cards, icons, light leaks, zooms, music, sound effects), with
stills in [`frames/`](frames/) and the transcript in [TRANSCRIPT.md](TRANSCRIPT.md).

The thank-you video to copy 1:1 for Jean (the video people see after they sign up or book).

- **The video itself:** it'll almost always be over 25 MB, so upload it to the
  [Thank-you VSL reference release](https://github.com/eliascroesus/jeanfx-vsl/releases/new?tag=thank-you-vsl-reference&title=Thank-you%20VSL%20reference).
  If GitHub asks about the tag, pick **Create new tag … on publish**, drag the video into the box at the bottom
  ("Attach binaries"), wait until it has finished uploading, then click **Publish release**.
- **Anything small** (screenshots of the page it sits on, notes, a link to where it's from): upload it straight into
  this folder with **Add file → Upload files**.

A line in `notes.md` on where the video is from and what you like about it helps.
