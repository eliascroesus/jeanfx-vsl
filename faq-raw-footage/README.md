# FAQ raw footage

The raw FAQ videos to edit (one short video per question).

- **Videos** are almost always over 25 MB, so upload them to the
  [FAQ raw footage release](https://github.com/eliascroesus/jeanfx-vsl/releases/new?tag=faq-raw-footage&title=FAQ%20raw%20footage).
  If GitHub asks about the tag, pick **Create new tag … on publish**, drag all the files into the box at the bottom
  ("Attach binaries"), wait until every file has finished uploading, then click **Publish release**.
- **Anything small** (notes, a reference FAQ video under 25 MB, screenshots): open this folder on GitHub, then
  **Add file → Upload files**, and make sure you're inside `faq-raw-footage/` before you drop them in.

Helpful but optional: a `notes.md` here with the question each video answers and anything that must (or must not) be
shown, and whether they should look like the VSL (AB's style) or the thank-you video (Iman-style graphics).
