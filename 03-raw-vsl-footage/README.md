# Raw VSL footage

Upload the raw, unedited recording of the VSL that needs editing. If it was recorded in several takes
or with separate audio, upload every file and note the order in a `notes.md` here.

Videos over 25 MB go in the [Raw VSL footage release](https://github.com/eliascroesus/jeanfx-vsl/releases/new?tag=raw-vsl-footage&title=Raw%20VSL%20footage) instead (see the main README).
